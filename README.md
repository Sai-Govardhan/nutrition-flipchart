# Nutritional Counselling Flip-Chart

A standalone, responsive 10-page flip-chart for the community project **Nutritional Counselling Kiosk for Tribal Anganwadis**.

## Files
- `index.html` — page structure
- `styles.css` — layout, colours, responsive styles and print rules
- `script.js` — 10 pages, navigation, Telugu text toggle and print control

## Preview locally
1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge or Firefox.
3. Use **Next / Previous** or the arrow keys.
4. Use **తెలుగు చూపించు** to show Telugu translation lines.
5. Use **Print** to print the flip-chart.

No build tools or package installation are required. Google Fonts are used when internet is available; system fallbacks are included.

## Publish a public link with GitHub Pages
1. Sign in to GitHub and create a new repository (for example `nutrition-flipchart`).
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under the build/deployment section, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for deployment. GitHub will display the public website URL in the Pages section. Open that URL in a private/incognito window to test access without sign-in.

## Before presenting
- Ask a fluent Telugu speaker or local Anganwadi Worker to review translations and terminology.
- Confirm local food examples and local government scheme/service details with official sources.
- The page is educational awareness material, not a substitute for individual medical advice.
